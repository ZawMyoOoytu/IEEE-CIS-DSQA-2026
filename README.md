# IEEE CIS DSQA 2026

Research and implementation workspace for the IEEE CIS 2026 Technical Challenge on Domain-Specific Question Answering with LLMs.

## Target Domains

- IFMIF-DONES particle accelerator domain
- Specialized AI research literature

## Research Direction

Trust-aware adaptive retrieval and reasoning for domain-specific question answering under fixed-model and computational constraints.

## Planned Pipeline

Question
    -> Question Analysis
    -> Adaptive Retrieval
    -> Evidence Trust/Relevance Scoring
    -> LLM Reasoning
    -> Answer Verification
    -> Final Answer

## Repository Status

Pre-challenge development.

The official challenge starter kit and evaluation interface will be integrated once they become available.
